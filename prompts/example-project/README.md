# Example Project

This is an example project demonstrating how to organize prompts within the PromptingVC structure.

## Project Description

This example project shows the recommended structure for managing prompts for an AI-powered code review assistant.

## Prompt Categories

### System Prompts (`system/`)
System-level prompts that define the AI agent's behavior, role, and capabilities.

### User Prompts (`user/`)
User-facing prompts for specific tasks or queries.

### Templates (`templates/`)
Reusable prompt templates that can be filled with specific parameters.

### Examples (`examples/`)
Example prompts showing different use cases and best practices.
